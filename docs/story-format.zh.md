# 场景 JSON 格式（当前版本）

[English](story-format.md)

本文描述的是 Gamiko App 目前读取**外部导入**视觉小说时使用的格式，例如用在线编辑器制作、以 PDF 分享的故事。带角色、声音、多语言包的增强版正在设计中，发布时会另行成文。现有格式的故事届时照常可用。

完整可玩的示例在 [`examples/lighthouse/`](../examples/lighthouse/)。

## 一段话说清模型

一个故事是由**场景**组成的图。每个场景是一串**步骤**（step）。每一步设定背景图，并显示一句或几句**台词**，一句占一屏。场景最后一句之后，要么让读者做**选择**，要么进入下一个场景，要么到达**结局**。

```
start ──▶ 2 ──┬─(选择)─▶ 3 ─▶ 4 ──┐
              └─(选择)─▶ 5 ─▶ 6 ──┴─▶ 7 ─▶ 8 ──┬─(选择)─▶ 9   （结局）
                                               └─(选择)─▶ 10  （结局）
```

## 顶层

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `title` | 字符串或 `{语种: 字符串}` | 是 | 标题 |
| `serial` | 字符串 | 是 | 唯一标识，建议用 UUID。App 靠它识别已经导入过的故事：serial 相同的文件会直接打开已有的那份，不会重新导入。**发布新版本时请换一个新的 serial。** |
| `scenes` | `{场景id: 场景}` | 是 | 必须包含名为 `"start"` 的场景 |
| `images` | `{图片id: 字节串}` | — | 由打包工具加入，不需要手写。见 [pdf-container.zh.md](pdf-container.zh.md) |

场景 id 是任意字符串，只有 `"start"` 有特殊含义。

## 场景 scene

| 字段 | 类型 | 含义 |
|---|---|---|
| `steps` | 步骤数组 | **必填**。也可以写成对象：此时键名只给人看，按键的顺序依次执行 |
| `background` | 字符串 | 第一步没写 `background` 时使用它 |
| `choices` | 选项数组 | 在最后一步的最后一句之后弹出。**有选项时 `next_scene` 与 `next_scenes` 都不生效** |
| `next_scene` | 字符串 | 没有选项时自动跳到这里。**没有 `next_scene`（且 `next_scenes` 没有命中）就表示本场景是结局** |
| `next_scenes` | `{场景id: 阈值}` | 按分数分流，规则见下文 |
| `effect` | 字符串 | 进入本场景的过渡效果：`"fade"` 淡入，`"space"` 穿梭特效 |
| `ending_name` | `{语种: 字符串}` | 结局名，读者到达结局时显示 |

## 步骤 step

| 字段 | 类型 | 含义 |
|---|---|---|
| `lines` | `[字符串]` 或 `{语种: [字符串]}` | 每个元素占一屏。句子里可以用 `\n` 换行，段落之间用 `\n\n` 隔开 |
| `background` | 字符串 | 更换背景，取值见「背景」一节。一直保持到后面的步骤再次更换 |
| `effect` | 字符串 | `"tremor"` 在本步开头开始震屏，`"stopTremor"` 停止震屏 |

当前的外部格式**没有角色和立绘**。有人说话时，把名字直接写进台词，例如 `"小渔：快看！"`。

## 选项 choice

| 字段 | 类型 | 含义 |
|---|---|---|
| `title` | 字符串或 `{语种: 字符串}` | 按钮上的文字 |
| `next_scene` | 字符串 | 选了之后去哪个场景 |
| `point` | 整数 | 可选。选中时加到故事的分数上 |
| `description` | `{语种: 字符串}` | 可选。场景有多个选项时，App 第一次点击显示这段说明，第二次点击才确认 |

## 分数与 `next_scenes`

每次游玩都有一个分数，进入 `start` 时清零，每选一个选项就加上它的 `point`。分数不写进文件。

没有选项的场景结束时，用当前分数 `pt` 和 `next_scenes` 里每一项的阈值 `t` 比较：

- `t > 0`：`pt >= t` 时命中，距离为 `pt - t`
- `t < 0`：`pt <= t` 时命中，距离为 `t - pt`
- `t = 0`：永远不命中

在所有命中项里取**距离最小**的那一个。一项都没命中就用 `next_scene`；它也没有，本场景就是结局。

```json
"judgement": {
  "steps": [{ "lines": ["议会安静下来。"] }],
  "next_scenes": { "hero": 5, "villain": -5 },
  "next_scene": "neutral"
}
```

## 背景

背景的取值有三种：

| 取值 | 含义 |
|---|---|
| `"@b<id>"` | 图片。打包工具读取故事旁边的 `images/<id>.png`，存到 `images["<id>"]` 下 |
| `"black"` `"white"` `"red"` `"green"` `"blue"` `"gray"` `"grey"` `"silver"` `"golden"` | 纯色 |
| `"#…"` | 十六进制颜色，字节顺序是引擎内部的 **AABBGGRR**。建议优先用颜色名 |

Gamiko App 使用的图片格式是 PNG，打包后的文件不能超过 **16 MB**。官方编辑器会把图片的长边限制在 1440 像素以内、宽高比限制在 9:16 到 16:9 之间，并自动压缩，保证整个文件放得下。本仓库的公开工具还接受 JPEG、WebP、GIF，因为它产出的文件只用于预览。

## 语种

故事用什么语言写都可以：普通字符串会原样显示。

一个文件也可以同时装几种语言。这时文字字段写成按语种分的对象，App 显示与设备语言对应的那一份。键名沿用引擎自己的语种代码：

| 代码 | 语言 |
|---|---|
| `en` `es` `pt` `ru` `ja` | 英、西、葡、俄、日 |
| `cn` | 简体中文 |
| `zh` | **繁体**中文 |

`ending_name` 和 `description` 一律按 `{语种: 字符串}` 读取。单语种的故事请把同一句话填到所有语种代码下，示例就是这么写的。

## 最小示例

```json
{
  "title": "那扇门",
  "serial": "0b5f3e8a-2f1c-4c0e-9d3a-7a1e2b3c4d5e",
  "scenes": {
    "start": {
      "steps": [
        { "background": "@b1", "lines": ["走廊尽头有一扇红色的门。", "门没有锁。"] }
      ],
      "choices": [
        { "title": "推开它", "next_scene": "inside", "point": 1 },
        { "title": "转身离开", "next_scene": "away" }
      ]
    },
    "inside": {
      "effect": "fade",
      "steps": [{ "background": "black", "effect": "tremor", "lines": ["地板在震动。"] },
                { "effect": "stopTremor", "lines": ["然后，一片寂静。"] }],
      "ending_name": { "en": "门内", "es": "门内", "pt": "门内", "ru": "门内", "ja": "门内", "zh": "門內", "cn": "门内" }
    },
    "away": {
      "steps": [{ "lines": ["你永远不会知道门后是什么。"] }],
      "ending_name": { "en": "离开", "es": "离开", "pt": "离开", "ru": "离开", "ja": "离开", "zh": "離開", "cn": "离开" }
    }
  }
}
```

用 `python3 tools/gmkvn.py check story.json` 检查故事。它会报告不存在的场景、缺失的图片、没有标题的选项，以及从 `start` 永远走不到的场景。
