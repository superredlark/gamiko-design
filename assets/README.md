# 📂 Assets Directory

This directory is the central hub for all creative resources used in Gamiko. 

---

## 🏗 Directory Structure

### 🖼 [/images](images/)
Contains all visual elements for different game modules.
* **`novelBackgrounds/`**: Scenery and environment art specifically for Visual Novel modules.
* **`novelActors/`**: Character sprites, expressions, and standing portraits for Visual Novels.
* **`gameBackgrounds/`**: Level backgrounds and static environments for casual game modules (e.g., Arcane Tower).
* **`gameActors/`**: Interactive items, props, and sprites for casual games (e.g., energy balls, stands).

### 📜 [/scripts](scripts/)
This directory is dedicated exclusively to **storytelling and narrative design**.
* **Plot Outlines**: Main story arcs, character biographies, and world-building documents.
* **Scripts & Dialogues**: Branching narratives, dialogue scripts, and scenario scripts specifically for the Visual Novel modules.
