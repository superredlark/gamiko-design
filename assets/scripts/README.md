# 📜 Scripts Directory

This directory contains the core narrative assets for Gamiko. The current files serve as real-world examples of how stories are integrated into the application.

---

## 📚 Current Series
* **Greek Mythology Series**: Modern reconstructions and critical choices based on classic myths.
* **Gothic Fairy Tales Series**: Dark, aesthetic, and immersive fairy tale narratives.

---

## ✍️ Writing & Contribution Guidelines

### 1. About File Formats
The `.json` sample files you see in this directory are the actual data formats running within the app. **Please note that these are for reference only, not a mandatory submission standard:**

* **Flexible Submission**: Since our visual design tools are still in development, **you are NOT required to submit content in JSON format**. You can submit your stories in Markdown, TXT, Word, or any plain text format you prefer. We will handle the technical conversion for you.
* **Revising Existing Stories**: If you wish to polish existing scripts directly within the JSON files, please ensure the code structure (braces and quotes) remains intact. If you are unsure, simply send us the revised text instead.

### 2. Narrative Requirements
* **Structure**: We encourage branching plots and decision points (choices). Whether it is a full script or a clear main storyline outline, your contribution is highly welcome.
* **Themes**: You are not limited to the current series. We encourage original ideas and limitless imagination.

### 3. Content Standards (Important)
To ensure the healthy growth of our community, please adhere to the following:
* **Copyright**: Do not submit any work with copyright disputes. All content must be original or legally authorized.
* **Content Rating**: Please keep the content family-friendly. **Avoid adult-oriented, excessively violent, or sexually explicit content that is unsuitable for minors.**
