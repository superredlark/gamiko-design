# 🖼 Images Directory

This directory contains the visual assets currently used in the live version of Gamiko. We believe in continuous improvement and welcome the community to refine, enhance, or completely reimagine these visuals.

---

## 📂 Sub-directories

* **`novelBackgrounds/`**: Environmental art and scenery for storytelling.
* **`novelActors/`**: Character designs, portraits, and emotional variants.
* **`gameBackgrounds/`**: Visual foundations for casual game levels.
* **`gameActors/`**: Functional sprites, items, and interactive elements.

---

## 🎨 Creative Guidelines

### 1. Refine or Replace
The existing files serve as the current baseline. If you believe you can create a **higher-quality version** of an existing asset (e.g., a more detailed background or a more expressive character), we strongly encourage you to submit your interpretation.

### 2. New Designs
Got a completely new idea? You are free to propose new assets that don't exist yet. 
* **Naming**: For new designs, feel free to **name files according to your preference** (e.g., `mystic_crystal_v1.png`). We will handle the integration and final indexing.
